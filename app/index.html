Часто задаваемые вопросы

Нужны ли знания для старта?

Нет. Курс рассчитан на новичков и начинается с самых основ javaScript.
Вы изучите:

  • переменные и типы данных
  • условия и циклы
  • функции и объекты
  • работу с DOM
  • асинхронность и API

Как проходит обучение?

Обучение полностью проходит онлайн.
Вам будут доступны:

  • видеоуроки
  • практические задания
  • проекты для портфолио
  • тесты и мини-чекпоинты
  • поддержка наставников
Вы сможете проходить материал в удобное время и возвращаться к урокам после завершения курса.

Сколько времени нужно уделять обучению?

В среднем студенты уделяют обучению 8-12 часов в неделю.
Этого достаточно, чтобы:

  • смотреть уроки
  • выполнять практические задания
  • работать над проектами
  • закреплять материал
график обучения гибкий, поэтому курс удобно совмещать с работой или учебой.

Какие проекты будут в моем портфолио?

Во время обучения вы создадите несколько практических проектов:

  • Landing page
  • Todo App
  • Weather App с API
  • Интерактивный Dashboard
  • SPA-приложение на React
Все проекты можно будет добавить в портфолио и показать работодателю.

Будет ли поддержка наставников?

Да. На протяжении всего обучения вы сможете обращаться к наставникам.
Поддержка включает:

  • ответы на вопросы
  • проверку домашних заданий
  • code review
  • помощь с ошибками
  • рекомендации по улучшению кода
В расширенном тарифе также доступны персональные консультации.

Выдается ли сертификат после окончания курса?

Да. После успешного завершения курса вы получите электронный сертификат.
Сертификат подтверждает:

  • прохождение программы
  • выполенение практических проектов
  • освоение ключевых навыков JavaScript и frontend-разработки

Можно ли найти работу после курса?

Курс помогает подготовиться к трудоустройству в сфере frontend-разработки.
В расширенном тарифе доступны:

  • помощь с резюме
  • оформление портфолио
  • подготовка к собеседованиям
  • mock interview
  • карьерные консультации
Также вы получите проекты, которые можно показать работодателям.

Останется ли доступ к материалам курса после его окончания?

да. После завершения курса у вас сохранится доступ:

  • к видеоурокам
  • практическим материалам
  • обновлениям программы
  • сообществу студентов
В тарифе "Максимум" доступ предоставляется без ограничений по времени.
